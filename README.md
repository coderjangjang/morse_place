# Morse

텍스트 대신 **모스부호로 대화하는 채팅 웹앱**이에요.

글자를 입력하면 모스부호로 바뀌어 전송되고, 탭 키를 직접 두드려서 보낼 수도 있어요. 받은 메시지는 모스부호와 해독된 글자를 같이 보여주고, 눌러서 소리로 들을 수도 있어요. 영문과 한글을 모두 지원하고, 별도 가입 없이 링크 하나로 방에 들어와서 바로 대화할 수 있어요.

- 프론트엔드: TypeScript + Vite (HTML / CSS / TS 모듈)
- 백엔드: Vercel Serverless Function (TypeScript) + Redis
- 실시간 방식: 폴링 (기본 1.5초, 활동이 없으면 최대 6초까지 늘어나요)

## 주요 기능

- **모스부호 입력**: 텍스트를 쓰면 자동 변환, 탭 키(스페이스바)로 직접 두드려도 입력돼요.
- **한/영 전환**: 입력창 왼쪽 `EN` / `한` 버튼으로 전환해요. 한글은 자모 단위 모스부호로 변환되고, 받는 쪽에서 다시 한글로 조합돼요.
- **소리 재생**: 메시지를 누르면 모스부호 소리로 재생하고, 재생 중인 부호가 강조돼요. 새 메시지 자동 재생 옵션도 있어요.
- **입력 중 표시**: 다른 사람이 메시지를 쓰는 중이면 입력창 위에 표시돼요. 설정에서 끌 수 있고, 끄면 내 상태도 공유하지 않아요.
- **접속자 수 · 새 메시지 알림**: 헤더에 접속자 수가 보이고, 위로 스크롤했거나 다른 탭에 있을 때 새 메시지가 오면 `새 메시지 ↓` 버튼과 탭 제목 숫자로 알려줘요.
- **방(room)**: `?r=방이름` 으로 방을 나누고, 초대 링크를 복사해서 공유해요.
- **메시지 삭제**: 내 메시지를 꾹 누르면 삭제해요. 관리자는 누구 메시지든 꾹 눌러 삭제할 수 있고, `/chatdel` 명령어도 있어요.
- **관리자 기능**: 차단, 타임아웃, 채팅 닫기, 슬로우 모드, 공지, 로그와 `관리자` 배지.
- **도배 방지**: IP 기준 전송 제한.
- **모스부호 표**: 설정 맨 아래에서 영문/한글 부호표를 보고, 눌러서 소리를 들을 수 있어요.
- **설정**: 테마(시스템/라이트/다크/터미널/세피아), 강조 색, 글자 크기, 탭 키 타이밍, 재생 속도 등. 브라우저에 저장돼요.

## 배포 (Vercel + Redis)

1. 이 프로젝트를 Vercel에 올려요. Vite 프로젝트로 자동 인식돼서 `npm run build` 결과(`dist/`)가 배포되고, `api/` 안의 TypeScript 함수는 Vercel이 알아서 빌드해요.
2. 환경변수를 설정해요.

   | 이름 | 설명 |
   | --- | --- |
   | `REDIS_URL` | Redis 접속 주소 (이름이 `REDIS_URL`로 끝나는 변수도 인식) |
   | `ADMIN_PASSWORD` | 관리자 비밀번호 (없으면 관리자 기능 비활성) |

서버가 연결되지 않으면 이 기기에서만 보이는 로컬 모드로 동작해요.

## 개발

```bash
npm install
npm run dev         # 화면만 실행 (Vite). 서버가 없으면 로컬 모드로 동작해요
npx vercel dev      # 화면 + API 함께 실행 (REDIS_URL, ADMIN_PASSWORD 필요)
npm run typecheck   # 프론트엔드 + 서버 타입 검사
npm run build       # 타입 검사 후 dist/ 로 빌드
```

`favicon.ico`는 `public/` 폴더에 넣어요.

## 사용법

- **텍스트로 보내기**: 입력창에 쓰고 `전송` (Enter로도 전송).
- **탭 키로 보내기**: 짧게 누르면 `·`, 길게 누르면 `−`. 데스크톱에서는 스페이스바도 탭 키로 쓸 수 있어요.
- **지우기**: `⌫` 한 글자, `✕` 전체.
- **메시지 듣기**: 말풍선을 눌러요.
- **내 메시지 삭제**: 내 말풍선을 꾹 눌러요(약 0.6초).
- **관리자 로그인**: 설정 → 관리자에 비밀번호 입력. 비밀번호는 저장되지 않고, 서버가 발급한 토큰(7일)만 브라우저에 저장돼요.

## 관리자 명령어

관리자로 로그인한 상태에서 입력창에 입력해요.

| 명령어 | 설명 |
| --- | --- |
| `/close` | 이 방의 채팅을 닫아요. 관리자 외에는 아무도 보낼 수 없어요. |
| `/open` | 닫은 채팅을 다시 열어요. |
| `/slow 초` | 슬로우 모드. 한 사람이 N초에 한 번만 보낼 수 있어요 (`0` 또는 `off`로 끄기, 최대 1시간). |
| `/notice 내용` | 방 상단에 공지를 고정해요 (`/notice off`로 내리기, 최대 200자). |
| `/ban 이름` | 해당 사용자(IP)를 차단 |
| `/unban 이름` | 차단·타임아웃 해제 |
| `/timeout 분 이름` | 지정한 시간(분) 동안 전송 제한 (최대 7일) |
| `/banlist` | 차단된 사용자 목록 |
| `/timeoutlist` | 타임아웃 중인 사용자와 남은 시간 |
| `/chatdel all` | 방의 모든 메시지 삭제 |
| `/chatdel 숫자` | 최근 메시지 N개 삭제 |
| `/chatdel 이름` | 해당 사용자의 메시지 삭제 |
| `/log [개수]` | 최근 관리자 명령 기록 (기본 10개, 최대 30개, 한국 시간) |
| `/help` | 명령어 목록 |

- `/ban`, `/timeout`은 이 방에서 최근 7일 안에 메시지를 보낸 기록이 있어야 대상을 찾을 수 있어요.
- 자기 자신(같은 IP)은 차단·타임아웃할 수 없어요.
- 숫자로만 된 이름은 `/chatdel 숫자`로 읽혀서 이름으로 삭제할 수 없어요.
- 관리자는 닫힘, 슬로우 모드, 차단, 도배 제한을 모두 받지 않아요.
- 닫힌 방은 7일 동안 아무 활동이 없으면 방 설정과 함께 초기화돼요.

## 한글 모스부호

표준 한글 모스부호(자모 단위)를 사용해요.

- 쌍자음, 겹받침, 복합모음(ㅘ, ㅢ 등)은 기본 자모를 이어서 표현해요.
- 받는 쪽에서 자모를 다시 글자로 조합해요.
- 부호 체계의 한계로 `가까`(ㄱㅏㄱㄱㅏ)처럼 받침인지 쌍자음 초성인지 구분할 수 없는 경우는 `각가`로 읽혀요.
- 영문과 한글은 같은 부호가 다른 글자라서, 메시지마다 `lang` 값을 함께 저장해요.

## API

`/api/messages`

요청·응답 타입은 `shared/types.ts`에 정의돼 있고, 서버와 프론트가 같이 써요. POST 요청은 `action` 값으로 구분되는 유니온 타입(`PostBody`)이에요.

### GET

`?room=방이름&since=마지막id&rev=삭제횟수&uid=기기ID`

- 최근 메시지 최대 100개 중 `since` 이후 것만 `msgs`로 반환해요. 각 메시지에는 내 메시지인지 나타내는 `mine`이 들어 있어요.
- `state`: 방 상태 `{ closed, slow, notice }`.
- `typing`: 지금 입력 중인 사람 이름들 (나는 제외).
- `online`: 접속 중인 사람 수 (최근 30초 안에 요청한 기기).
- `rev`가 서버의 삭제 횟수와 다르면 남아 있는 메시지 목록(`cids`, `from`)을 함께 보내서 클라이언트가 삭제된 메시지를 정리해요.

### POST

| 요청 | 설명 |
| --- | --- |
| `{ room, name, morse, lang, cid, uid, key? }` | 메시지 전송 (`lang`: `en` / `ko`). 닫힌 방이면 `403 closed`, 슬로우 모드면 `429 slow` |
| `{ action: 'del', room, cid, uid, key? }` | 메시지 삭제 (보낸 기기 본인 또는 관리자) |
| `{ action: 'auth', key }` | 관리자 로그인 (비밀번호 → 토큰 발급) |
| `{ action: 'logout', key }` | 관리자 토큰 폐기 |
| `{ action: 'cmd', room, key, text }` | 관리자 명령어 실행 (`key`는 토큰) |
| `{ action: 'typing', room, uid, name, on, key? }` | 입력 중 표시 켜기/끄기 |

## 제한과 보관

- 방마다 최근 **200개**만 보관하고, 7일 동안 활동이 없으면 방이 자동 삭제돼요.
- 도배 제한(IP 기준): 10초에 8개 초과 시 30초 차단, 10분에 80개 초과 시 5분 차단. 관리자는 제한이 없어요.
- 관리자 로그인 실패 5회 시 10분 동안 잠겨요.
- 관리자 토큰은 7일간 유효하고, `ADMIN_PASSWORD`를 지우면 모두 무효가 돼요.
- 이름은 최대 12자예요. `admin`, `관리자`, `운영자`가 들어간 이름은 관리자가 아니면 `OP`로 바뀌어요.
- 메시지의 보낸 사람 확인용으로 기기 ID 해시를 저장하고, 클라이언트에는 내려주지 않아요. IP 원본은 이름 → IP 조회(`/ban`, `/timeout`용)에만 7일간 보관해요.
- 입력 중 표시는 4초, 접속자 표시는 30초 뒤에 저절로 사라져요.
